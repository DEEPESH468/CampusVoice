# Data

`demo_feedback.csv` is entirely synthetic illustrative data created for project demonstrations. It does not represent real college feedback. Its `sentiment` labels are supplied for comparing/evaluating the classroom example classifier and must not be treated as a representative validation set.

For classifier training, upload a labelled CSV with required columns `comment` and `sentiment`; labels must be Positive, Neutral, or Negative. Collect consent, remove identifying details, and use a representative sample before making real-world claims.
